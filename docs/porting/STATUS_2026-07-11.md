## 1. 产品定位（当前）

Linux 原生 **Avalonia 工作台**，覆盖原版日常打标主路径：

- 打开数据集 → 缩略图列表  
- 编辑当前图标签（中文对照 / 权重 / 上下移 / 过滤）  
- 全部标签表（中文 / 计数 / 过滤 / 添加到当前）  
- 预览 Tab  
- WD14 ONNX（当前 / 多选 / 全部 + 进度取消），CUDA 可用  

**不是** WinForms Plus 1:1 全功能克隆。
